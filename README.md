# Data Cleaning & Preparation (DecodeLabs Project 1)

Cleaned a dataset of 1,200 orders using Google Sheets.

## What I did
- Filled 309 blank CouponCodes with "NONE" (blank = no coupon used)
- Checked duplicates: 0 duplicate OrderIDs
- Checked dates: 0 incorrectly formatted dates
- Set prices to 2 decimal places

- change_log.pdf: what I changed and why
