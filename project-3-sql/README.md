# SQL Analysis: DecodeLabs Project 3

SQL queries on 1,200 customer orders (Jan 2023 to Jun 2025), run with
SQLite in Google Colab.

## SQL used
SELECT, WHERE, ORDER BY, GROUP BY, COUNT, SUM, AVG

## Key findings
- Only about 19% of orders were delivered (231 of 1,200)
- Chair, Printer and Laptop earn the most across all orders
- Delivered revenue is about 242.6k, versus about 1.26M for all orders
- Product rankings change when only delivered orders are counted
- Average order value differs little by payment method (1,002 to 1,128)
